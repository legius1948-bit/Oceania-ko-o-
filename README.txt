KOŁO FORTUNY OFC FIFA — GitHub Pages

Lista zawiera 11 federacji członkowskich OFC:
Samoa Amerykańskie, Wyspy Cooka, Fidżi, Nowa Kaledonia, Nowa Zelandia, Papua-Nowa Gwinea, Samoa, Wyspy Salomona, Tahiti, Tonga, Vanuatu.

Publikacja:
1. Utwórz osobne repozytorium, by nie nadpisać poprzednich kół.
2. Wgraj wszystkie pliki do katalogu głównego i kliknij Commit changes.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Otwórz adres pokazany przez GitHub Pages w Safari.
5. Udostępnij → Dodaj do ekranu początkowego.

Uwaga: lista jest oparta na członkach OFC; sprawdź oficjalną stronę OFC/FIFA, jeśli potrzebujesz potwierdzenia aktualnego statusu członkostwa.
